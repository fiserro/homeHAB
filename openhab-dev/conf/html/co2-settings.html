Auto Baseline Calibration (ABC)

ABC automatically calibrates the sensor every 24h using the lowest observed value as 400 ppm. Disable if the sensor never sees fresh outdoor air.

Zero Point Calibration
Postup kalibrace:
  1. Otevři šasi rekuperace
  2. Odpoj senzor z potrubí a vytáhni ho ven na čerstvý vzduch (okno / balkon)
  3. Počkej minimálně 20 minut
  4. Zkontroluj, že hodnota CO2 nahoře se ustálila
  5. Stiskni tlačítko Calibrate Zero Point
  6. Vrať senzor zpět do potrubí a zavři šasi

Tip: Dělej kalibraci při výměně filtru (každých 90 dní). Nekalibruj, dokud je senzor v potrubí!
